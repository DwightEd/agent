# 部署与运维

## 本地启动

```bash
python -m backend.server --host 127.0.0.1 --port 8000 --db data/researchops.db
```

首次访问创建管理员；密钥缺省时演示模式仍可完整运行。默认仅监听本机。持久文件为 SQLite 主文件及运行时的 WAL/SHM；不要只复制一个正在写入的 `.db` 文件。

环境变量说明见 `.env.example`。直接 Python 启动时使用 shell export 或 PowerShell 环境变量赋值，程序不会自动读取 `.env`。

## Docker

```bash
cp .env.example .env
# 写入随机 BOOTSTRAP_TOKEN；真实模式再填写 LLM_API_KEY 与模型配置
docker compose up --build
```

容器非 root 运行，使用命名卷持久化 `/app/data`，默认只映射主机 loopback 的 8000 端口。访问初始化表单时填写 `.env` 中的 BOOTSTRAP_TOKEN；初始化完成后此令牌不能再创建管理员。

当前环境未实际构建 Docker 镜像，首次使用请在目标主机验证镜像构建和卷权限。

## 共享部署

定位是早期团队私有化试点，使用单服务实例和 TLS 反向代理。不要直接把 Python 标准库 HTTP 服务裸露到公网。

1. 在 Nginx/Caddy 配置 TLS、请求超时、请求体大小限制和入口速率限制。
2. 设置 `APP_HOSTS=research.example.com`，多个主机名以逗号分隔，不含协议、路径或端口。反向代理保留原始 Host。
3. HTTPS 下设置 `COOKIE_SECURE=1`；不允许默认公开注册，管理员在界面创建成员。
4. API Key 通过部署环境或密钥管理注入。不要提交 `.env` 或数据库。
5. 只运行一个服务实例；多进程部署需要另行实现租约型任务队列。

允许本地 HTTP 模型服务；远端模型 Base URL 必须为 HTTPS。实际模型服务的可用性、响应格式、费用和数据保留政策由部署者确认。

## 停止、取消与恢复

任务请求取消后，当前模型请求最多等待 60 秒，arXiv 最多 30 秒，然后停止。进程正常退出时，当前任务会保存为 cancelled 并可在界面重试；硬退出遗留的 running 状态在下次启动时恢复。已经完成的角色阶段保留，不重复执行；中断阶段可能重复模型请求或只读工具。

实验审批保存在数据库，服务恢复后不会自动批准。已获得审批且存在缓存结果的实验不会重复计算。

调用预算是请求次数上限，不是美元成本上限；模型返回的 token 用量只用于统计。预算包含失败 HTTP 尝试和重试。达到上限后任务失败，旧任务的重试不会增加预算；需要新建任务并设置适当上限。

## 备份与恢复

```bash
python scripts/backup.py --db data/researchops.db --output backups/researchops-2026-09-22.db
```

使用 SQLite [在线备份 API](https://docs.python.org/3/library/sqlite3.html#sqlite3.Connection.backup)，支持服务运行时生成一致性快照。备份含账户和资料，应按敏感项目数据管理。

恢复步骤：停止服务；保留当前数据文件作为回滚副本；将备份复制到一个**新的数据库路径**；用 `--db` 指向该路径启动。使用新路径避免残留 WAL/SHM 与恢复的主文件混用。先核对项目、任务和报告，再决定是否替换原来的运行目录。

## 常见问题

| 现象 | 处理 |
|---|---|
| Host 未获准 | APP_HOSTS 添加实际访问主机名并重启；代理保留 Host |
| Docker 首次初始化被拒绝 | 设置 BOOTSTRAP_TOKEN 并在初始化表单中填写 |
| 真实模式提示缺少密钥 | 在启动服务的同一环境设置 LLM_API_KEY，或配置本地服务 |
| HTTP 401/404 模型错误 | 检查模型服务 Base URL（通常到 /v1）、密钥与模型名 |
| agent 达到 8 轮仍未完成 | 模型可能不支持工具调用/JSON 或能力不足；换模型后新建任务 |
| 没有可引用资料 | 导入至少一份相关原文，或调整检索目标并开启 arXiv |
| 任务等待审批 | 打开运行页查看参数，批准或拒绝实验 |
| PDF 无内容 | 扫描件无可提取文本；先 OCR，或上传纯文本 |
| 引文校验持续失败 | 检查原始资料可读性；模型必须摘录实际存在的原文 |
| 定时任务没运行 | 确保服务持续运行、项目未归档且无同项目活动任务 |
| 已修改环境模型但界面没变 | 管理员已保存的数据库配置优先；在设置页修改 |

没有连接邮件、支付、云算力或外部项目管理系统，任务不会主动向这些服务发起业务操作。
